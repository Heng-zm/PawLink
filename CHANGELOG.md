# Changelog

## 4.2.0 — Google Sans and easier navigation

- Applied Google Sans Flex across the landing page, authentication screens, dashboard, and controls.
- Added Google Sans as the recommended public-profile font and made it the default for new profiles.
- Reorganized Appearance into four focused sections: Colors, Background, Typography, and Cards.
- Added grouped sidebar navigation for Build and Manage tasks.
- Added a page-status card with copy/open actions in the sidebar.
- Simplified the top bar to show the current task, publishing status, preview, and save state.
- Added quick actions on the Home dashboard.
- Added a five-tab mobile bottom navigation bar.
- Updated API profile validation and migration support for the `google` font option.
- Updated integration tests for version 4.2 and the new default font.
